## 🎯 ¿Qué es esto?

**Booking Plans** es una herramienta de inteligencia de mercado para la industria musical. No es solo un directorio—es un **activo estratégico** que permite:

✅ Identificar venues por capacidad y género  
✅ Acceder a contactos verificados en la industria  
✅ Evaluar modalidades de negociación por nivel de riesgo  
✅ Planificar giras y eventos con data real

## 🎯 Casos de Uso

### 1. Planificar una Gira
- Filtra venues por capacidad (500-1000 personas)
- Identifica ciudades clave (CDMX → GDL → MTY)
- Contacta promotores directos

### 2. Buscar Venue por Género
- Navegá a "Géneros Musicales"
- Selecciona tu género (ej: Rock, Metal, Punk → 50+ venues)
- Revisa venues destacados

### 3. Evaluar Riesgo de Negociación
- Revisa "Modalidades de Negociación"
- Elige según tu nivel de experiencia
- Bajo Riesgo: Fecha Comprada / Versus Deal
- Alto Riesgo: Door Deal (para artistas establecidos)
